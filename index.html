06 / Contact Command

Each body receives one upcoming contact target

One command per body

3D target + active flag.

Active means a contact is expected within 1.5 seconds.

Coordinate frame

Origin at the base; vertical aligned with gravity; horizontal axes follow base heading.

Contact bodies: hands, feet, knees, elbows, pelvis. Inactive targets are ignored. ACP contact interface.

07 / Dense Six-Axis Tactile Feedback

Each sensing element measures six force/torque components

Controller input

Element positions and force/torque histories, together with robot motion.

Test against simpler sensing

Pressure maps, total six-axis force/torque, and dense three-axis forces.

F: force; T: torque. x, y, z: sensor axes. Torque is about each element’s reference point. Slip velocity and friction limits require inference. Frame conventions.

13 / Lower-Tail CVaR

CVaR averages the lowest-return fraction of episodes

Conditional value at risk (CVaR) evaluates the return distribution.

CVaRα↓(Gθ,α)=maxη{η−1α𝔼[(η−Gθ,α)+]}

α
Fraction of lowest returns

η
Optimized return threshold

(η − G)⁺
max(η − G, 0)

α = 0.1

Average the worst 10%.

α = 1

Recover expected return.

G is the discounted return defined on p12. CVaR is an episode-level objective, not an extra per-step reward. Chow et al., 2015.

14 / Chosen RL Objective

Our main objective replaces mean return with CVaR

Main method

maxθCVaRα↓(Gθ,α)

Vary α as the single user command.

Alternative: weight mean and tail performance

maxθ[(1−λ)𝔼[Gθ,α]+λCVaRα↓(Gθ,α)]

λ ∈ [0, 1]. Use λ = 1 for the main method; test a fixed λ < 1 as an ablation.

Chow & Ghavamzadeh, 2014

Train across α values. The actor update must optimize this objective; a distributional critic alone is insufficient.

15 / Constrained MDP Alternative

A constrained MDP needs an explicit cost budget

Constrained Markov decision process (CMDP). cₜ: nonnegative safety cost. C: episode cost. b: allowed expected cost.

Cθ,α=∑t=0T−1ct
maxθ𝔼[Gθ,α]subject to𝔼[Cθ,α]≤b

Example

C = 1 for a fall, 0 otherwise.
𝔼[C] equals fall probability.

Current proposal

CVaR of return, without a cost constraint.
α is not a failure-probability limit.

Achiam et al., 2017

A fixed penalty is not a constraint. An upper-tail CVaR cost constraint is another option; see Notes.

The study tests two measurable claims

Risk-conditioned planning

Does one planner change contact strategy and improve lower-tail return when α changes?
